How it works. The badge can only be claimed by the owner of an Agent ID NFT and stays bound to that Agent ID. Check in once a day to grow your Agent ID's public reputation. Other dApps can read isVerifiedAgent() and pointsOfAgent() on-chain.

Safety. Free forever — no mint price, no sale, no promise of returns; you only pay your own BNB gas. The contract has no owner and no admin functions; badges can never be transferred. This page never asks for seed phrases, private keys, or wallet pairing codes.
